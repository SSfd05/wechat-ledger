## 6. 用户隐私保护指引（重要）

本小程序会调用剪切板接口：

- `wx.getClipboardData`：读取用户主动复制的账单文本
- `wx.setClipboardData`：把导出数据复制到剪切板

在「设置 → 服务内容声明 → 用户隐私保护指引」中：

- 收集的信息类型：勾选「剪切板」
- 用途说明（可复制）：

```
读取用户主动复制的账单文本，用于自动识别记账金额与分类；不存储、不上传剪切板内容。
```

- 其他信息：不收集位置、相册、摄像头、麦克风、通讯录、手机号、微信头像昵称
- 数据存储：仅保存在用户本机的小程序本地缓存
- 第三方共享：无

如果页面没有「剪切板」选项，以页面实际选项为准；发布前建议补全声明，否则部分机型调用剪切板可能失败。

## 7. 服务器域名

## 常见卡点

| 问题 | 处理 |
| --- | --- |
| 名称被占用 | 依次尝试备选名称 |
| 类目没有「记账」 | 选「工具 → 效率」，介绍里强调记录/效率 |
| 隐私指引找不到剪切板 | 以页面选项为准；发布前补声明 |
| 头像审核不通过 | 用提供的纯图形头像，避免文字堆叠、二维码、联系方式 |
| 介绍被驳回 | 去掉「自动」「智能」之外的绝对化用语，保留功能描述 |
